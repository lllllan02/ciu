插入排序（Insertion Sort）是一种 **原地** 比较排序算法：维护左端已排序前缀，逐个将 `arr[i]` 插入正确位置。平均与最坏时间复杂度 $O(n^2)$，最好（已有序）$O(n)$；**稳定**，数据近乎有序时表现很好。

本实现从 `arr[i]` 出发向左扫描，若左侧相邻元素更大则交换，直至就位或遇到 `arr[j + 1] >= arr[j]`。

## API

| 函数 | 说明 |
| :--- | :--- |
| `insertion_sort(arr, len)` | 对 `arr[0..len-1]` 升序排序 |

## 算法步骤

整体流程：外层 `i` 扩展已排序前缀；内层将 `arr[i]` 通过相邻交换逐步左移，插入到有序段中的正确位置。

1. **外层循环**：`i` 从 `0` 到 `len - 1`，`arr[0..i-1]` 为已排序区间。
2. **内层扫描**：`j` 从 `i - 1` 递减到 `0`，比较 `arr[j + 1]` 与 `arr[j]`。
3. **终止**：若 `arr[j + 1] >= arr[j]`，说明 `arr[i]` 已就位，`break`。
4. **交换**：否则交换 `arr[j]` 与 `arr[j + 1]`，继续向左。
5. **一轮结束**：`arr[0..i]` 有序，下一轮 `i++`。

### 核心循环

```c
void insertion_sort(int* arr, int len) {
    for (int i = 0; i < len; i++) {
        for (int j = i - 1; j >= 0; j--) {
            if (arr[j + 1] >= arr[j]) break;

            swap(arr + j, arr + j + 1);
        }
    }
}
```

### 一轮插入示意

以 `[5, 3, 8, 4, 2]` 为例，第二轮（`i = 1`，待插入 `3`）内层过程：

| 步骤 | `j` | 比较 | 交换后 |
| :--- | :--- | :--- | :--- |
| 初始 | — | — | `[5, 3, 8, 4, 2]` |
| 1 | `0` | `3 < 5` | `[3, 5, 8, 4, 2]` |

`3` 就位；后续轮次依次插入 `8`（无需交换）、`4`、`2`，直至全部有序。

## 与常见写法的对比

| | 本实现（相邻交换） | 常见变体（元素后移） |
| :--- | :--- | :--- |
| 插入方式 | 交换 `arr[j]` 与 `arr[j + 1]` | 保存 `key`，将较大元素右移一格 |
| 写操作 | 交换 | 赋值移动 |
| 稳定性 | 稳定（`>=` 时 `break`） | 稳定（通常用 `>` 判断后移） |
| 最好情况 | $O(n)$ | $O(n)$ |
| 核心思想 | 将 `arr[i]` 向左冒泡到正确位置 | 将 `arr[i]` 插入有序前缀 |

本实现用 `arr[j + 1] >= arr[j]` 作为终止条件，相等元素不交换，保证 **稳定性**。

## 复杂度分析

设数组长度为 $n$。

| 项目 | 平均 | 最坏 | 最好 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **时间** | $O(n^2)$ | $O(n^2)$ | $O(n)$ | 已有序时内层首轮即 `break`；逆序时约 $\Theta(n^2)$ 次比较与交换 |
| **额外空间** | $O(1)$ | $O(1)$ | $O(1)$ | 原地，仅常数辅助变量 |
| **稳定性** | 稳定 | 稳定 | 稳定 | 仅在 `arr[j + 1] < arr[j]` 时交换，相等元素保持原序 |
