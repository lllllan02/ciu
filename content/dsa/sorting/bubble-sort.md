冒泡排序（Bubble Sort）是一种 **原地** 比较排序算法：相邻元素两两比较，若前者大于后者则交换，使较大元素逐步「冒泡」到序列末尾。平均与最坏时间复杂度 $O(n^2)$；**稳定**，教学常用，实际工程较少采用。

本实现采用双重循环：外层控制已就位区间右边界，内层在相邻元素间比较并交换。

## API

| 函数 | 说明 |
| :--- | :--- |
| `bubble_sort(arr, len)` | 对 `arr[0..len-1]` 升序排序 |

## 算法步骤

整体流程：每轮内层扫描将当前未排序区间中的最大值交换到右端，已排序区间从右向左扩展。

1. **外层循环**：`i` 从 `len - 1` 递减到 `0`，表示未排序区间的右边界（不含 `i` 右侧）。
2. **内层扫描**：`j` 从 `0` 到 `i - 1`，比较 `arr[j]` 与 `arr[j + 1]`。
3. **交换**：若 `arr[j] > arr[j + 1]`，交换两者。
4. **一轮结束**：`arr[i]` 为当前未排序区间的最大值，下一轮缩小右边界。

### 核心循环

```c
void bubble_sort(int* arr, int len) {
    for (int i = len - 1; i >= 0; i--) {
        for (int j = 0; j < i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr + j, arr + j + 1);
            }
        }
    }
}
```

### 一轮扫描示意

以 `[5, 3, 8, 4, 2]` 为例，第一轮（`i = 4`）内层比较过程：

| 步骤 | 比较 | 交换后 |
| :--- | :--- | :--- |
| 1 | `5 > 3` | `[3, 5, 8, 4, 2]` |
| 2 | `5 < 8` | 不变 |
| 3 | `8 > 4` | `[3, 5, 4, 8, 2]` |
| 4 | `8 > 2` | `[3, 5, 4, 2, 8]` |

第一轮结束后 `8` 就位；后续轮次在 `[3, 5, 4, 2]` 上继续，直至全部有序。

## 与常见写法的对比

| | 本实现 | 常见变体 |
| :--- | :--- | :--- |
| 外层循环 | `i` 从 `len - 1` 递减 | `i` 从 `0` 递增，或固定 `n - 1` 轮 |
| 内层范围 | `j < i` | `j < len - 1 - i` |
| 提前终止 | 无 | 某轮无交换则 `break`，最好 $O(n)$ |
| 核心思想 | 相邻比较、大元素右移 | 相同 |

本实现未做「某轮无交换则提前结束」的优化，因此 **最好情况仍为 $O(n^2)$**；若加入 `swapped` 标志，已有序输入可降至 $O(n)$。

## 复杂度分析

设数组长度为 $n$。

| 项目 | 平均 | 最坏 | 最好（本实现） | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **时间** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | 外层约 $n$ 轮，内层比较次数约 $n + (n-1) + \cdots + 1$ |
| **额外空间** | $O(1)$ | $O(1)$ | $O(1)$ | 原地，仅常数辅助变量 |
| **稳定性** | 稳定 | 稳定 | 稳定 | 仅在 `arr[j] > arr[j + 1]` 时交换，相等元素不交换 |
