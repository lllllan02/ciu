## 定义

冒泡排序（Bubble Sort）是一种简单的 **原地** 比较排序算法。执行过程中，较小的元素像气泡一样逐步「浮」到数列一端，较大的元素沉到另一端，故称为冒泡排序。

## 过程

工作原理：从左到右依次比较 **相邻两个** 元素，若前者大于后者则交换。一趟扫描下来，当前未排序部分中的最大值会逐步「沉」到右端。

重复上述扫描。每完成一趟，右端就多确定一个最大值；最多 $n - 1$ 趟即可排完全部元素。若某一趟全程没有发生交换，说明已有序，可以提前结束。

![冒泡排序动画](/images/bubble-sort.gif)

下方动图初始为 `[3, 44, 38, 5, 47, 15, 36, 26, 27, 2, 46, 4, 19, 50, 48]`。每趟从左到右相邻比较，较大者右移；大数像气泡一样逐步「沉」到右端。前几趟结果如下：

| 趟次 | 结果 | 说明 |
| :--- | :--- | :--- |
| 第 1 趟 | `[3, 38, 5, 44, 15, 36, 26, 27, 2, 46, 4, 19, 47, 48,` `50]` | 开头 `44 > 38`、`44 > 5` 等连续交换；`50` 沉到末尾 |
| 第 2 趟 | `[3, 5, 38, 15, 36, 26, 27, 2, 44, 4, 19, 46, 47,` `48, 50]` | `48` 沉到倒数第二位 |
| 第 3 趟 | `[3, 5, 15, 36, 26, 27, 2, 38, 4, 19, 44, 46,` `47, 48, 50]` | `47` 沉到倒数第三位 |

此后每趟再确定一个右端位置，直至全部有序。

## 性质

### 稳定性

冒泡排序是 **稳定** 排序算法。仅在相邻两元素前者严格大于后者时才交换，相等元素不会互换位置，相对顺序保持不变。

### 时间复杂度

| 情况 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **最好** | $O(n)$ | 已有序时，一趟扫描无交换即可结束 |
| **最坏** | $O(n^2)$ | 逆序时约 $\frac{(n-1)n}{2}$ 次比较与交换 |
| **平均** | $O(n^2)$ | 随机数据下比较次数同阶 |

### 空间复杂度

$O(1)$。原地排序，仅使用常数个辅助变量。

## 代码实现

> 源码: https://github.com/lllllan02/ciu/tree/master/code/bubble-sort

本仓库实现。用 `flag` 标记本轮是否发生交换，某轮无交换则提前结束：

```c
static void swap(int* a, int* b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

void bubble_sort(int* arr, int len) {
    if (len <= 1) return;

    bool flag = true;
    while (flag) {
        flag = false;
        for (int i = 0; i < len - 1; i++) {
            if (arr[i] > arr[i + 1]) {
                flag = true;
                swap(arr + i, arr + i + 1);
            }
        }
    }
}
```
