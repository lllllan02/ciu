## 定义

希尔排序（Shell Sort）也称缩小增量排序，是[插入排序](/dsa/sorting/insertion-sort)的改进版本：按固定间隔将数组分成若干子序列分别做插入排序，再逐步缩小间隔，最终间隔为 1 时完成整体排序。

插入排序的弱点在于每次只能把元素移动 **一位**。元素离目标位置很远时，要经历大量相邻交换，最坏 $O(n^2)$。但它对 **近乎有序** 的数据很快（最好 $O(n)$）。

希尔排序的优化思路是：先用 **较大间隔** 做插入排序，让元素能一次跨越多个位置，快速接近目标区域；间隔逐步缩小后，数组已「大致有序」，最后的间隔为 1 的插入排序只需少量调整。换言之，用粗粒度的预排序，降低细粒度插入排序的工作量。

## 过程

工作原理：**间隔** 即分组时的步长 —— 按间隔取值，相隔该步长的元素归为同一子序列（间隔 4 时，`8` 与 `7` 同组，`3` 与 `5` 同组，依此类推）。对每个子序列分别做插入排序，再缩小间隔重复；直至间隔为 1，即对整个数列做一次普通插入排序。

常用间隔从约一半长度开始，每轮减半，直至 1。以 `[8, 3, 1, 2, 7, 5, 6, 4]` 为例，各趟分组与组内排序如下（同组元素按从左到右在数列中的先后列出）：

| 间隔 | 组数 | 各组元素 | 排序结果 |
| :--- | :--- | :--- | :--- |
| 4 | 4 | `[8, 7]`、`[3, 5]`、`[1, 6]`、`[2, 4]` | `[7, 8]`、`[3, 5]`、`[1, 6]`、`[2, 4]` |
| 2 | 2 | `[7, 1, 8, 6]`、`[3, 2, 5, 4]` | `[1, 6, 7, 8]`、`[2, 3, 4, 5]` |
| 1 | 1 | `[1, 2, 6, 3, 7, 4, 8, 5]` | `[1, 2, 3, 4, 5, 6, 7, 8]` |

第一趟按初始数列分组。此后每趟先将 **上一趟写回后的数列** 重新分组——例如间隔 4 写回后得 `[7, 3, 1, 2, 8, 5, 6, 4]`，再按间隔 2 分组才是 `[7, 1, 8, 6]` 与 `[3, 2, 5, 4]`；间隔 1 同理，在间隔 2 写回后的 `[1, 2, 6, 3, 7, 4, 8, 5]` 上排序。

## 性质

### 稳定性

希尔排序是 **不稳定** 排序算法。根本原因在于 **间隔大于 1** 时做的是跨距插入排序：元素会与相隔多个位置的元素互换，不同子序列被搅在一起；即使相等键本身不直接交换，其他元素的远距离移动仍可能把相等键 **带到对方前面**。

相等时不交换，只能避免相等键 **直接** 互换，**不能**保证稳定——问题出在间隔大于 1 时的 **跨组换位**。

以 `[8, 5b, 5a, 1]` 为例（`5b`、`5a` 值均为 5），间隔序列为 2、1：

| 阶段 | 操作 | 结果 |
| :--- | :--- | :--- |
| 间隔 2 | `5a` 与 `8` 互换 | `[5a, 5b, 8, 1]` |
| 间隔 2 | `1` 与 `5b` 互换 | `[5a, 1, 8, 5b]` |
| 间隔 1 结束后 | — | `[1, 5a, 8, 5b]` |

输入时 `5b` 在 `5a` 前面，最终 `5a` 在 `5b` 前面，相对顺序被破坏。最后一轮间隔 1 的插入排序也无法挽回这种错位。

### 时间复杂度

时间复杂度与 **增量序列** 的选取有关。

| 情况 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **最好** | $O(n \log n)$ | 已有序时内层可提前 `break` |
| **最坏** | $O(n^2)$ | 本实现采用希尔增量（$n/2, n/4, \ldots, 1$） |
| **平均** | $O(n \log n)$ ~ $O(n^{3/2})$ | 取决于增量序列；实践中优于简单二次排序 |

选用 Knuth 增量（$1, 4, 13, \ldots$，即 $3h+1$）等序列可进一步降低复杂度上界。

### 空间复杂度

$O(1)$。原地排序，仅使用常数个辅助变量。

## 代码实现

> 源码: https://github.com/lllllan02/ciu/tree/master/code/shell-sort

### 基础写法

本仓库实现。希尔增量（`len/2` 减半至 1），通过间隔交换完成子序列插入：

```c
static void swap(int* a, int* b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

void shell_sort(int* arr, int len) {
    for (int gap = len >> 1; gap > 0; gap >>= 1) {
        for (int i = gap; i < len; i++) {
            for (int j = i - gap; j >= 0; j -= gap) {
                if (arr[j + gap] >= arr[j]) break;

                swap(arr + j, arr + j + gap);
            }
        }
    }
}
```

### 优化写法

采用 Knuth 增量序列（初始 `gap` 取不超过 `len/3` 的最大 $3h+1$），保存 `key` 后移元素，减少交换次数：

```c
void shell_sort(int* arr, int len) {
    int gap = 1;
    while (gap < len / 3) gap = gap * 3 + 1;

    while (gap > 0) {
        for (int i = gap; i < len; i++) {
            int key = arr[i];
            int j = i - gap;
            while (j >= 0 && arr[j] > key) {
                arr[j + gap] = arr[j];
                j -= gap;
            }
            arr[j + gap] = key;
        }
        gap /= 3;
    }
}
```
