## 定义

选择排序（Selection Sort）是一种简单直观的 **原地** 比较排序算法。每次从未排序区间中找出最小元素，与区间左端交换，使已排序区间从左向右扩展。

## 过程

工作原理：将数列分为左侧 **已排序** 与右侧 **未排序** 两部分。每轮在未排序部分找出最小值，与未排序部分的第一个元素交换，已排序区间便向左扩展一位。

![选择排序动画](/images/selection-sort-animate.svg)

下方动图初始为 `[8, 2, 6, 3, 10, 9, 4, A, 7, 5]`，`A` 视作 `1`（Ace）。每趟扫描未排序部分找最小值（动图中以颜色标记），再与左端交换；已排序部分逐步从左向右扩展。前几趟结果如下：

| 趟次 | 结果 | 说明 |
| :--- | :--- | :--- |
| 第 1 趟 | `[A, 2, 6, 3, 10, 9, 4, 8, 7, 5]` | 最小值 `A` 与左端 `8` 交换 |
| 第 2 趟 | `[A, 2, 6, 3, 10, 9, 4, 8, 7, 5]` | 最小值 `2` 已在左端，无需交换 |
| 第 3 趟 | `[A, 2, 3, 6, 10, 9, 4, 8, 7, 5]` | 最小值 `3` 与 `6` 交换 |

此后每趟再确定一个左端位置，直至全部有序。

## 性质

### 稳定性

选择排序是 **不稳定** 排序算法。每轮把未排序部分的最小值与左端 **互换** 时，左端原有的元素会直接跳到最小值原来的位置——可能远在后面；若有相等键，相对顺序可能就此打乱。相等时优先选较左的最小值，只决定「选哪个」，**不能** 阻止左端元素被换到后面。

以 `[3b, 3a, 1]` 为例（`3b`、`3a` 值均为 3）：

| 趟次 | 操作 | 结果 |
| :--- | :--- | :--- |
| 第 1 趟 | 最小值 `1` 与左端 `3b` 交换 | `[1, 3a, 3b]` |
| 第 2 趟 | 最小值 `3a` 已在左端，无需交换 | `[1, 3a, 3b]` |

输入时 `3b` 在 `3a` 前面，排序后 `3a` 在 `3b` 前面，相对顺序被破坏。

### 时间复杂度

| 情况 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **最好** | $O(n^2)$ | 比较次数固定，已有序时仍须扫完全部区间 |
| **最坏** | $O(n^2)$ | 约 $(n-1) + (n-2) + \cdots + 1$ 次比较 |
| **平均** | $O(n^2)$ | 随机数据下比较次数同阶 |

交换次数至多 $n - 1$ 次；本实现在 `i == min` 时跳过交换，已有序输入可降至 $O(1)$ 次交换。

### 空间复杂度

$O(1)$。原地排序，仅使用常数个辅助变量。

### 基础写法

本仓库实现。每轮找最小下标，仅在 `i != min` 时交换，避免无意义的自交换：

```c
static void swap(int* a, int* b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

void selection_sort(int* arr, int len) {
    for (int i = 0; i < len; i++) {
        int min = i;
        for (int j = i + 1; j < len; j++) {
            if (arr[j] < arr[min]) min = j;
        }

        if (i != min) swap(arr + i, arr + min);
    }
}
```
