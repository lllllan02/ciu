选择排序（Selection Sort）是一种 **原地** 比较排序算法：每轮从未排序区间中选出最小元素，与区间左端交换，使已排序区间从左向右扩展。平均、最好与最坏时间复杂度均为 $O(n^2)$；**不稳定**，交换次数至多 $n - 1$ 次。

本实现每轮用内层循环找最小下标 `min`，仅在 `i != min` 时交换，避免无意义的自交换。

## API

| 函数 | 说明 |
| :--- | :--- |
| `selection_sort(arr, len)` | 对 `arr[0..len-1]` 升序排序 |

## 算法步骤

整体流程：外层 `i` 划定已排序前缀 `[0, i)` 与未排序后缀 `[i, len)`，每轮将后缀最小值放到 `arr[i]`。

1. **外层循环**：`i` 从 `0` 到 `len - 1`，`arr[0..i-1]` 为已排序区间。
2. **找最小**：令 `min = i`，内层 `j` 从 `i + 1` 扫描到 `len - 1`，若 `arr[j] < arr[min]` 则更新 `min`。
3. **交换**：若 `i != min`，交换 `arr[i]` 与 `arr[min]`。
4. **一轮结束**：`arr[i]` 为全局第 `i` 小的元素，下一轮 `i++`。

### 核心循环

```c
void selection_sort(int* arr, int len) {
    for (int i = 0; i < len; i++) {
        int min = i;
        for (int j = i + 1; j < len; j++) {
            if (arr[j] < arr[min]) min = j;
        }

        if (i != min) swap(arr + i, arr + min);
    }
}
```

### 一轮扫描示意

以 `[5, 3, 8, 4, 2]` 为例，第一轮（`i = 0`）找最小值过程：

| 步骤 | `j` | 比较 | `min` |
| :--- | :--- | :--- | :--- |
| 初始 | — | — | `0`（值 `5`） |
| 1 | `1` | `3 < 5` | `1` |
| 2 | `2` | `8 > 3` | `1` |
| 3 | `3` | `4 > 3` | `1` |
| 4 | `4` | `2 > 3` | `1` |

交换 `arr[0]` 与 `arr[1]` 后得 `[3, 5, 8, 4, 2]`；后续轮次在 `[5, 8, 4, 2]` 上继续，直至全部有序。

## 与冒泡排序的对比

| | 选择排序（本实现） | 冒泡排序 |
| :--- | :--- | :--- |
| 每轮操作 | 找最小下标，至多交换 1 次 | 相邻比较，可能多次交换 |
| 交换次数 | 至多 $n - 1$ 次 | 可达 $O(n^2)$ 次 |
| 比较次数 | $\Theta(n^2)$ | $\Theta(n^2)$ |
| 稳定性 | **不稳定** | 稳定 |
| 适用场景 | 交换代价高时更有优势 | 教学演示、近乎有序时可优化至 $O(n)$ |

本实现在 `i == min` 时跳过交换，已有序输入仍须完成全部 $\Theta(n^2)$ 次比较，时间复杂度不变。

## 复杂度分析

设数组长度为 $n$。

| 项目 | 平均 | 最坏 | 最好 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **时间** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | 外层 $n$ 轮，内层比较约 $(n-1) + (n-2) + \cdots + 1$ 次 |
| **交换** | $O(n)$ | $O(n)$ | $O(1)$ | 每轮至多 1 次交换；已有序时 `i == min` 可跳过 |
| **额外空间** | $O(1)$ | $O(1)$ | $O(1)$ | 原地，仅常数辅助变量 |
| **稳定性** | 不稳定 | 不稳定 | 不稳定 | 远距离交换可能打乱相等元素的相对顺序 |
